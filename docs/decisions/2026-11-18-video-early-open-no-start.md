# Opening the video room early does not start the visit

Date: 2026-11-18 · Owner report: a test join at 11:33 marked a 1:15 visit as started.

- Start Video Visit stamps the start only once the visit's window has opened. That is 15 minutes before the scheduled start, the same window the patient's Join button uses, read in Georgia.
- Pressed earlier, it opens the room and stamps nothing, and says so.
- A start that was stamped before the window opened, with no end yet, is reset the first time the room is opened inside the window. The reset is recorded as a correction with a reason, so the history keeps the early stamp.
- If the calendar can't be read, the start is stamped as before. A missing time statement costs more than an early one.
