# An I-9 already on file (2026-11-13)

**Owner:** some employees completed their I-9 in Gusto. Can that count?

**Change.** Payroll → People → a person now has an **I-9 already on file** box. It appears until their I-9 is complete. The Super Admin enters:
- where it came from (Gusto or a paper form)
- the first day of work shown on the form
- optionally, the date Section 2 was completed
- a tick confirming the signed copy is filed on their Staff Record (Documents → Work authorization documents)

**What the employee sees.** The I-9 counts as complete, and payroll no longer lists it as missing. Their Pay Setup row reads "Already on file from your earlier hire paperwork," with no Start button.

**Why.** A completed Form I-9 stays valid when an employer changes payroll provider. Asking for Section 1 again was more than the rule requires. Requiring the copy on file keeps the form producible on request.

**Route.** `PUT /api/payroll/admin/people/:userId/i9-on-file` (`requireAdmin`). It refuses without the first day or the filed-copy tick, and refuses an I-9 that is already complete.

**Tests.** One test in `test/payroll.test.js`; making `i9Complete` ignore `onFile` fails it. Full suite: 3700 pass, 0 fail.
