# Godwins Family Care — Website UI Kit

A high-fidelity recreation of a marketing site for Godwins Family Care, built from the brochure content + brand notes (no production codebase was provided).

## Files

- `index.html` — full-page recreation: header → hero → services → CCM band → process → testimonials → contact → footer
- `App.jsx` — top-level layout
- `Header.jsx` / `Footer.jsx`
- `Hero.jsx` — split layout, navy + photo
- `ServiceTiers.jsx` — three pricing tiers
- `ContinuousCare.jsx` — CCM hybrid monitoring band
- `Process.jsx` — five numbered steps
- `Testimonials.jsx` — quote cards on navy
- `ContactForm.jsx` — referral / consultation form
- `Button.jsx`, `Eyebrow.jsx`, `Section.jsx` — atomic primitives

## Notes

- All copy is lifted directly from the brochures so it reads true to brand voice.
- Photography uses the user-provided assets in `assets/`.
- Interactive bits (form submit, nav links) are mocked — this is a UI kit, not production code.
